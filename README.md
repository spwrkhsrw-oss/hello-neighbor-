AyoChill Bot

A simple Discord role-management bot built around the ".ayochill" command.

About

Devleak is a furry boy. 🐾

This bot is made for giving server roles quickly and easily, while restricting the command to members who have the required authorization role.

Command

I'm not your dad to tell you

Example:

I'm you

Only members with the configured authorization role can use the command.

Requirements

- Python 3.10+
- "discord.py"
- A Discord bot token
- Manage Roles permission for the bot
